## User personas

Six personas built from 267 interviews, 158 G2 reviews, Dovetail's Brand Value Stream
research and 90 days of product behaviour.

**Live artifact:** https://claude.ai/artifact/FaBjbFu7hiM5LYBfALemAQ — private, ask the
UX Research team for access.

Every claim carries its denominator, every persona carries a confidence score, and the
gaps are stated as prominently as the findings. See [`personas/README.md`](personas/README.md).

## Skills

Agent Skills follow the [open specification](https://agentskills.io/specification) and
the conventions used in the UX DesignOps skill pack. To use one, copy its folder into
`.agents/skills/` in the consuming project, or install the DesignOps pack and drop it
alongside the rest.
